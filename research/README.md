# Fawkner Mansions — Research & Development Register

This directory is the evidence and version-control layer for the Fawkner Mansions project.

## Rules
- Every substantial research pass is a numbered, immutable run under `research/runs/`.
- The newest run is shown by default in `admin/research.html`; older runs remain selectable.
- Historical claims are classified as: **verified primary**, **official secondary**, **reputable media**, **owner/operator statement**, **marketing claim**, **review-platform snapshot**, **user-supplied material**, **community anecdote**, **inference**, or **unresolved**.
- New runs must explicitly record **new revelations**, **contradictions**, **corrections to earlier runs**, and **open questions**.
- Volatile data such as review scores is always date-stamped.
- Sensational, reputational or potentially defamatory claims are not promoted from a user-supplied or secondary source without checking the underlying source.
- Image provenance and reuse rights must be recorded before public publication.
