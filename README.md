# Fawkner Mansions — Book & Heritage Documentation Project

Research, writing, and digital-preservation project centred on **Fawkner Mansions**,
250 Punt Road, Prahran, Victoria 3181 — a heritage-listed 1910–11 Edwardian Free
Classical block of flats designed by Ernest H. Willis, and believed to be the oldest
surviving residential flats in the City of Stonnington.

This repository is the working store of context for the project: the heritage record,
the book concept, the preservation/VR plan, and the existing "Mansion WiFi" guest
portal built for the building's router.

- [`wifi-portal/`](wifi-portal/) — an existing "Mansion WiFi" captive-portal splash
  page and OpenWrt/openNDS router configuration built for the building, with a
  heritage-grounded design (oxblood brick, bluestone, cream render, black iron).

## Project goals

1. A hardcover A5 book on the building's history, architecture, and residents —
   print-on-demand via Amazon KDP, with a small print run for heritage groups,
   local libraries, and universities.
2. A 3D model of the building (interior and exterior) for digital preservation and
   a future VR walkthrough, in case the building is ever altered or demolished.
3. A companion website showcasing the building's history and imagery.
4. A short (15–20 minute) history documentary for social media and web distribution.
